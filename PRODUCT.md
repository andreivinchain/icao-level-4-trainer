# Aero English — концепция MVP

## Концепция

Мобильный тренажёр для короткой ежедневной практики ICAO English Level 4. Пользователь проходит урок-ситуацию, закрепляет активную лексику, разыгрывает Pilot–ATC сценарий и проверяет ответ по шести критериям ICAO.

## Информационная архитектура

- Главная: общий прогресс, ежедневная практика, рекомендованный урок, быстрые действия.
- Уроки → урок: цель, лексика, фразы, аудио, speaking task, отметка завершения.
- Лексика → карточки: поиск, категории, изученные слова, сенсорный режим карточек.
- Сценарии: ситуация, роли, диалог, практическое продолжение, self-check.
- Экзамен: три последовательных текстовых задания и критерии самопроверки.
- Прогресс: серия, время, уроки, слова, активность по шести навыкам.
- Настройки: тема, аудио, локальный сброс данных.

## Модель данных

Основные сущности: `CourseLesson`, `CourseTest`, `VocabularyItem`, `Scenario`, `ExamPrompt`, `Progress`. Учебные данные вынесены в `app/course-data.ts`; пользовательские состояния (`lessons`, `tests`, `exercises`, `words`, `streak`, `minutes`) хранятся в `localStorage` под ключом `icao-progress`.

## Обработка книги

Обе PDF-версии — 123-страничные сканы без текстового слоя. Все страницы распознаны локально с OCR. В приложение перенесены все 30 units со страниц 8–77, Progress tests 1–6, Review tests 1–2, словарные блоки Vocabulary Check и привязка к CD1–CD3. Структура каждого unit: Describe the picture → questions → sample answer → Plain English gist/detail → radiotelephony listening → Plain English → clarification role-play → vocabulary → discussion. Формулировки сокращены и адаптированы для приложения, без длинного дословного копирования книги.

## MVP

Девять требуемых экранов, 30 units × 10 упражнений, 8 контрольных тестов, 240 словарных карточек, 30 сценариев, 136 локальных аудиотреков, экзаменационный режим, localStorage, адаптивная навигация, светлая/тёмная тема и web app manifest.

## Развитие

1. Редакторская вычитка OCR для малоконтрастных подписей и схем.
2. Интерактивные вопросы с автоматической проверкой по Answer Key.
3. Запись речи, waveform и повтор фрагмента.
4. AI-feedback по шести критериям с обязательной пометкой, что это не официальная оценка ICAO.
5. Spaced repetition, синхронизация аккаунта и преподавательская панель.

## Запуск

Установить зависимости: `npm install`. Запустить локально: `npm run dev`. Проверить production-сборку: `npm run build`.
